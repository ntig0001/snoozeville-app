# Snoozeville Safety & Patrol Report
A responsive web application that presents a municipal safety report with modern UI, interactive navigation, and a mobile-friendly layout.

## 🚀 Live Demo
https://ntig001.github.io/snoozeville-app/

## 📌 Features
* Responsive layout (mobile + desktop)
* Overlay sidebar navigation
* Section-based report structure
* Interactive chat widget UI
* Printable report (PDF export via browser)
* Clean component-based architecture (React)

## 🛠️ Built With
* React
* Vite
* Tailwind CSS
* Lucide Icons

## 📂 Project Structure
src/
  assets/
    App.jsx
    index.css
    main.jsx
  components/

## ⚙️ Getting Started

  ### Install dependencies
  npm install

  ### Run locally
  npm run dev

  ### Build for production
  npm run build

  ## 🚀 Deployment
  This project is deployed using GitHub Pages.
  To deploy: npm run deploy

## 📄 Notes
* Designed as a front-end demonstration of a dummy municipal reporting system
* Chat functionality is UI-only (no backend integration)
